# Legacy frontend code

These files are preserved for reference but are not part of the active Next.js application.

- `admin/`: the former admin UI, which depended on the removed Express/MongoDB backend.
- `api-tools/`: local media conversion and inspection routes with machine-specific tooling.
- `philosophy/`: the previous editable philosophy section.
- `sections/`: superseded page sections.
- `showcase/`: unused animation concept components.
- `vite/`: the original Vite entry files retained as migration history.

The production application lives in `src/app` and uses components from `src/components`.
